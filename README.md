# To-Do List Web App
This is a dynamic To-Do List built using HTML, CSS, and Vanilla JavaScript.

## Features
- Add tasks
- Press Enter to add task
- Mark tasks as complete
- Delete tasks
- Data saved using LocalStorage

## Concepts Used
- DOM Manipulation
- Event Listeners
- JavaScript ES6
- LocalStorage

## How to Run
Open index.html in browser.
